# Column Customization in Blazor TreeGrid

This sample explains how to customize column headers and data in the Syncfusion Blazor TreeGrid component (Blazor WebAssembly, .NET 10) using the template option.

**Documentation**: https://help.syncfusion.com/grid-sdk/blazor/tree-grid/getting-started

**Online examples**:

* https://blazor.syncfusion.com/demos/tree-grid/column-template?theme=fluent2
* https://blazor.syncfusion.com/demos/tree-grid/header-template?theme=fluent2

## Features

* Customizing column header text and field mappings.
* Defining column widths for improved data presentation.
* Changing column text alignment for better readability.
* Applying data formatting to numeric and date columns.
* Configuring different column types based on the underlying data.
* Showing or hiding columns dynamically.
* Reordering columns to customize the column layout.
* Resizing columns interactively at runtime.
* Freezing columns to keep important information visible during horizontal scrolling.
* Enhancing TreeGrid appearance through flexible column configuration options.

## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Visual Studio 2026 / Visual Studio Code

## How to Run the Project

**Visual Studio 2026**

1. Clone or download this repository.
2. Open the project file:

   `TreeGridColumnCustomization.csproj`

3. Restore all NuGet packages.
4. Build the project.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root.

```bash
cd column-customization-in-blazor-treegrid
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
