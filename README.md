# Column Customization in Blazor TreeGrid

This sample explains how to customize column headers and data in the Syncfusion Blazor TreeGrid component (Blazor WebAssembly, .NET 10) using the template option.

**Documentation**: https://help.syncfusion.com/grid-sdk/blazor/tree-grid/getting-started

**Online examples**:

* https://blazor.syncfusion.com/demos/tree-grid/column-template?theme=bootstrap4
* https://blazor.syncfusion.com/demos/tree-grid/header-template?theme=bootstrap4

## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Visual Studio 2022 / Visual Studio Code

## Project structure (.NET 10)

```
├── App.razor
├── _Imports.razor
├── Program.cs
├── TreeGridColumnCustomization.csproj
├── Layout/               # MainLayout
├── Models/               # Employee
├── Pages/                # Home (Tree Grid column customization sample), NotFound
├── Properties/           # launchSettings.json
└── wwwroot/              # index.html, css, images, bootstrap
```

## How to run the project

* Checkout this project to a location in your disk.
* Restore the NuGet packages by rebuilding the project.
* Run the project.
